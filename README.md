# Htmllearn: Web Engineer Master Academy

## Using it

- **Claude Code:** copy Part A of v7 into `CLAUDE.md` (see Part D, section D0), then say "start".
- **Any chat:** paste the whole v7 file as your first message. At the end of each session, save the State Capsule (section D6) and paste it back in next time.
